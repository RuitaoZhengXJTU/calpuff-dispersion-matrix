# Legacy Sparse Workflow

This directory retains superseded sparse candidate, initial-response, MMIF,
surrogate, smoke, and assembly scripts. They are kept to explain historical
intermediate work, not as default production commands. Shared executable
resolution, hashes, logs, and time parsing now live in
`src/calpuff_matrix/runtime.py`.

Use the `calpuff-matrix` commands documented in the root README for formal
CALMET/CALPUFF/CALPOST matrix generation.
