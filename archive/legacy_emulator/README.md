# Legacy Emulator

This directory retains the earlier CALPUFF-style fallback/emulator, pseudo
meteorology, and partition-comparison code for provenance. It estimates a
transport operator and is not a CALPUFF/CALPOST result. It is not collected by
the active test suite and is not part of the default reproduction path.

Use `calpuff-matrix prepare`, `build-weather`, `build-calmet`, and `run` for
the formal workflow.
